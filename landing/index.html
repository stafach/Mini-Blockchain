Core Features

Built for speed, security & clarity

Every component is transparent and educational, from the low-level C core to the live web UI.

C Hashing Core

High-performance SHA-256 engine written in C for efficient block mining and cryptographic security. Proof-of-Work included.

Multi-Transaction Ledger

Supports multiple transactions per block, each cryptographically linked and fully visualizable in the web interface.

Integrity Validation

Instantly detects any tampering or hash mismatches across the chain via the /validate endpoint.

System Design

How it all connects

Three layers working in concert: a C engine, a Python/Flask API bridge, and a real-time web frontend.

The Story Behind

Why I built this

I recently became interested in blockchain and decentralized technologies. As I explored this field, I realized that to truly understand it, I needed to learn the technical foundations not just use existing libraries.

That's why I joined Holberton School with the goal of becoming a blockchain developer. Working on this project helped me deeply understand how a blockchain functions and confirmed that this is the path I want to follow.

This portfolio project was completed in one month as part of the Holberton School fundamentals program.
